# 🟦 Jorge — HTML Pixel Art

**Arquivo:** [index.html](index.html)

Edição de navegador com renderização em resolução reduzida (pixel art). Pode ser aberta no Chrome, Edge ou navegador do celular, com teclado, toque e controles reconhecidos.

**Importante:** esta é uma versão HTML, não é o APK nem a ROM de Mega Drive. Seu código fica separado do HTML normal.

Para testar localmente, baixe o arquivo `index.html` desta pasta e abra no navegador.
