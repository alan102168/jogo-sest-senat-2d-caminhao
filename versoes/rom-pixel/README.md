# 🎮 Jorge — ROM Mega Drive Pixel Art

**[Código do jogo 16 bits](https://github.com/alan102168/jogo-sest-senat-2d-caminhao/tree/rom-pixel-art/megadrive)**

**[Baixar ROM e capa em Releases](https://github.com/alan102168/jogo-sest-senat-2d-caminhao/releases)**

A ROM `Jorge_Truck_Driver.bin` é compilada com SGDK, com sprites e cenário em tiles de 8×8 pixels. A capa `Jorge_Truck_Driver.png` é gerada com o mesmo nome para facilitar a organização no M8 Lite.

**Não é um APK e não é HTML renomeado.** Antes de usar no Game Stick M8 Lite, faça backup do cartão e teste a ROM num emulador compatível. O funcionamento no seu aparelho ainda precisa ser confirmado.
