# 📂 Versões do Jorge

Aqui ficam as edições independentes do jogo.

1. [HTML normal](html-normal/) — jogo de navegador com gráficos originais.
2. [HTML Pixel Art](html-pixel/) — jogo de navegador com pixels grandes.
3. [Android normal](android-normal/) — aplicativo Android original.
4. [Android Pixel Art](android-pixel/) — aplicativo Android com arte pixelada.
5. [ROM Mega Drive Pixel Art](rom-pixel/) — ROM `.bin` para emulador de Mega Drive.

Também há um [menu visual em HTML](index.html). O jogo normal segue em [https://jorgethetruckdriver.vercel.app/](https://jorgethetruckdriver.vercel.app/).
